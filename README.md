# Универсальный контроллер ввода (WASD и стрелочки)
---

Input Controller - универсальный контроллер, реализующий абстрактный интерфейс между источником ввода (клавиатура, тач-панель, мышь, геймпад, танцевальный коврик и т.д.) и функциональной частью приложения.
Этот контроллер необходим для того, чтобы можно было добавить в приложение новые устройства ввода или модифицировать существующие, не трогая основную часть приложения, так как этот контроллер преобразует все внешние сигналы в стандартный понятный приложению формат.

---

При переключении пользователем фокуса с окна, в котором работает контроллер. он не генерирует события.

---

index.html - основная страница с интерфейсом для тестирования и визуализацией интерактивного элемента.
input-controller.js - контроллер.
input-controller-test.js - инициализация контроллера и функционал для проверки его работоспособности.
